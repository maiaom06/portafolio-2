# Maia Ospina — sitio web personal

Sitio web estático, responsive y listo para desplegar en un hosting estático (Netlify, Vercel, GitHub Pages o servidor web tradicional).

## Archivos
- `index.html`: estructura y contenido del sitio.
- `styles.css`: identidad visual, diseño responsive y animaciones.
- `script.js`: menú móvil, filtros de proyectos, animaciones al desplazarse y barra de progreso.
- `assets/`: fotografías y recursos visuales extraídos de los documentos entregados.

## Vista local
Abre `index.html` en un navegador. Para probarlo con servidor local, desde esta carpeta ejecuta:

```bash
python3 -m http.server 8000
```

Luego visita `http://localhost:8000`.

## Publicación
Sube la carpeta completa `maia_site` a tu proveedor de hosting. No requiere compilación ni dependencias de Node.

## Antes de publicar
- Verificar que los datos de contacto sigan vigentes.
- Confirmar el orden y la descripción final del reconocimiento CLAEP Challenge: el CV indica tercer puesto y el portafolio menciona segundo y tercer lugar del equipo.
- Revisar que los enlaces externos de los proyectos continúen disponibles.
- Añadir enlaces específicos de redes sociales si se desea mostrarlos.

## Nota de contenido
La sección de proyectos diferencia ejercicios académicos de experiencia laboral. La dirección física no se publica; se muestra únicamente Cali, Valle del Cauca.
